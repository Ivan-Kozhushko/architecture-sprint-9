| F2    | Возможность подачи заявки на депозит через сайт|Новые клиенты оставляют ФИО и телефон, после чего с ними связывается менеджер.|

| U1    | Придерживаться системы дизайна принятой в компании. |              |
| U2    | Интерфейс открытия депозита должен быть максимально удобным для клиента. | Допущение: минимум шагов, необходимые подсказки, форма обратной связи по процессу открытия. |

| R1    | Все сервисы должны работать 24/7 и быть доступны в 99,9% случаев. | Поэтому лучше избежать прямой работы интернет-банка с API АБС в новом процессе. |
| R2    | В случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку. | У банка есть резервный ЦОД, в случае сбоя необходимо переключиться на него. Время восстановления не должно превышать 15 минут, допустимое время простоя не более 0.1% в месяц. |
| R3    | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД. | Учесть, что АБС может масштабироваться только вертикально из-за своей базы данных. |

| S   | Поддерживаемость (Supportability)  |              |
| S1    | При доработках во всех системах нужно как можно больше использовать технологии, которые уже есть в банке. | Например, базы данных MS SQL и Oracle. |
| S2    | Нужно разработать документацию для дальнейшего расширения системы. |              |
| +R  | + Ограничения (Restricitions)      |              |

| +5    | Нужно учитывать, что АБС может масштабироваться только вертикально из-за своей базы данных |              |
| +6    | Данные клиентов полученные на сайте и в интернет банке необходимо шифровать при передаче. |              |
